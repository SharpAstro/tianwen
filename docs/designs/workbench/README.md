# Workbench design (#2553)

The owner's mockup of the redesigned processing app (`tianwen-edit`), kept with the code. Each file is HTML with the
screen's data in the script at its end; open it in a browser. Copied unchanged from the design session.

- `Import.dc.html`: New project, what is in the folder. The groups detected on the left, the chosen group's files on the
  right with kind, why, exposure, filter, temperature and grade; a per-file kind dropdown; a "Needs a look" group.
- `Workflow.dc.html`: New project, choose a workflow. The workflows that fit and why, the ones that do not, the chosen
  one's tree previewed.
- `Main.dc.html`: the workbench. Project tree, panel of the selected step or frame group, canvas, toolbar, status strip.

The design language is `.github/docs/design-language.md` in the org root.
